🎯 Array-Only Tree View - Test Cases

This document demonstrates the expected behavior of the modified tree view components when displaying only JSON array fields.

Test Case 1: Simple Array

Description: Object with one array field and one non-array field 
{
  "users": ["user1", "user2", "user3"],
  "name": "test",
  "count": 3
}
Expected Behavior:
  • Only "users" array should be visible
  • "name" string should be hidden
  • "count" number should be hidden
  • Root object should show "Object (1 arrays)"

Test Case 2: Nested Arrays

Description: Nested object structure with arrays at multiple levels 
{
  "departments": [
    {
      "name": "Engineering",
      "teams": [
        { "name": "Backend", "size": 5 },
        { "name": "Frontend", "size": 3 }
      ]
    },
    {
      "name": "Sales",
      "teams": [
        { "name": "Enterprise", "size": 10 }
      ]
    }
  ],
  "company": "ACME Corp",
  "founded": 2020
}
Expected Behavior:
  • "departments" array visible with checkbox
  • Department items visible (to navigate to nested arrays)
  • "teams" nested array visible with checkbox
  • "company" and "founded" fields hidden
  • "name" and "size" inside team items hidden

Test Case 3: No Arrays

Description: Object with only primitive fields, no arrays 
{
  "name": "John Doe",
  "age": 30,
  "active": true,
  "email": "john@example.com"
}
Expected Behavior:
  • Show empty state message
  • Display: "No array fields detected in the data structure."
  • Show info icon

Test Case 4: Arrays of Arrays (Matrix)

Description: Array containing nested arrays (2D array structure) 
{
  "matrix": [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
  ],
  "dimensions": "3x3"
}
Expected Behavior:
  • "matrix" array visible with checkbox
  • Array items [0], [1], [2] visible (as they are arrays)
  • Nested arrays within matrix items visible
  • "dimensions" string hidden

Test Case 5: Complex Mixed Structure

Description: Complex object with arrays at various nesting levels 
{
  "metadata": {
    "version": "1.0",
    "tags": ["tag1", "tag2", "tag3"]
  },
  "data": {
    "records": [
      {
        "id": 1,
        "values": [10, 20, 30],
        "label": "Record A"
      },
      {
        "id": 2,
        "values": [40, 50, 60],
        "label": "Record B"
      }
    ],
    "summary": "Test data"
  },
  "timestamp": "2024-01-01"
}
Expected Behavior:
  • "metadata" object visible (contains "tags" array)
  • "tags" array visible with checkbox
  • "data" object visible (contains "records" array)
  • "records" array visible with checkbox
  • Record items visible (contain "values" arrays)
  • "values" nested array visible with checkbox
  • "version", "id", "label", "summary", "timestamp" hidden

Test Case 6: Root Array

Description: JSON structure where root itself is an array 
[
  {
    "id": 1,
    "items": ["a", "b", "c"]
  },
  {
    "id": 2,
    "items": ["x", "y", "z"]
  }
]
Expected Behavior:
  • Root array visible
  • Array items [0], [1] visible (contain "items" arrays)
  • "items" nested array visible with checkbox
  • "id" fields hidden

Test Case 7: Deep Nesting

Description: Deeply nested array structure 
{
  "level1": {
    "level2": {
      "level3": {
        "items": [
          {
            "subitems": [
              { "value": 1 }
            ]
          }
        ]
      }
    }
  }
}
Expected Behavior:
  • "level1", "level2", "level3" objects visible (navigation path)
  • "items" array visible with checkbox
  • Items visible (contain "subitems")
  • "subitems" nested array visible with checkbox
  • "value" primitive hidden

📋 Implementation Details

Key Implementation Features:
  • containsArrays() Helper: Recursively checks if a value contains arrays
  • shouldShowNode Computed: Controls node visibility based on array content
  • filteredObjectChildren: Filters object properties to show only array-containing ones
  • filteredArrayChildren: Filters array items to show only those with nested arrays
  • Path Building: Correctly builds paths for nested structures
  • Empty State: Shows message when no arrays exist

🧪 Testing Instructions

How to Test:
  1. Navigate to Step 3 (Schema Configuration) in the wizard
  2. Load sample data with various array structures
  3. Verify the tree view shows ONLY array fields
  4. Check that non-array fields are completely hidden
  5. Confirm nested arrays appear as children
  6. Test selection functionality (checkboxes work correctly)
  7. Verify empty state appears when no arrays exist
